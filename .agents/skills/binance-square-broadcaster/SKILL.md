## 2. Compliance & Publishing Protocols
1. **Mandatory Risk Disclaimer**: Every generated post must conclude with a clear non-financial advice disclosure.
2. **Coin Cashtags**: Format tokens with the standard Binance cashtag prefix (e.g., `$BNB`, `$BTC`, `$ETH`, `$SOL`) for automatic hashtag discovery on Binance Square.
3. **No Key / PII Leakage**: Strip internal account IDs, API session keys, and exact master wallet totals from public post bodies.
